## Tiers

- **Critical (≥8.0)** — high-impact, low-effort, novel for you. Adopt immediately.
- **High (7.0–7.9)** — meaningful value, worth the time.
- **Medium (5.5–6.9)** — situational. Useful if your context matches.
- **Low (<5.5)** — reference only. Don't expect to adopt.

Tutorials with Novelty ≤ 2 auto-cap at Low regardless of impact.

## Status values

- `draft` — being written
- `review` — needs human review pass
- `published` — ready to use
- `archived` — superseded by a newer tutorial or no longer relevant
