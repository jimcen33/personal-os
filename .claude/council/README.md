# .claude/council/

Optional. Role-specialized decision lenses that pair with `/skeptic` to break confirmation bias on high-leverage decisions.

- Each role is a folder with a `CONTEXT.md` — copy `_template/CONTEXT.md` to start.
- Roles are *lenses*, not yes-men: each charter biases toward dissent.
- Full setup, suggested role set, and the calibration loop: `docs/extending/council.md`.

Delete this whole folder if you don't want the Council layer — nothing else depends on it.
